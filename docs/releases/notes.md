## 上下文用量面板

点输入条上沿那条潮线，展开的是完整拆分：百分比、已用/剩余分段条（85% 处一条临界刻度）、
上次请求占用、其中命中缓存、上次输出、模型声明的窗口。数字用 k/M 缩写并等宽对齐；
窗口没声明的模型显示「未声明」——**不给分母，也不编**。

## 版式改按 open-vetta 的规矩重做

参考它 `packages/ui` + `theme-ui` 的实测规格（不留印象值）：

- **内容变平，玻璃只留给 chrome**：分区卡是实色面 + 1px 实线 + 圆角 12；顶栏、输入条、弹层才是玻璃
- **行**：44 高、标题 14/500、说明 12/70%、行间 0.5px 细线（原来是 2px 的缝，读作"一堆小卡片"）
- **开关**：18.4×32（原来是 Material 的 52×32，笨重），命中区外扩 12×8
- **按钮**：32 高、圆角 8、**按下整体下移 1px**（不是缩放或变暗）
- **输入框**：32 高、边框 60%、聚焦 3px/30% 主色环
- **空态**：图标砖 48 + 13/600 + 11/70%，只有真的没数据才给按钮
- **用户气泡**：中性灰面、宽 72%、圆角 16 而右下收成 6、14/1.6
- **对话内错误行不再整行红**：标题 85%、红只留一个图标

所有新组件的动画统一走一个闸门：系统"移除动画"为真时一律零时长，光感档位关掉"预见性动画"时列表不再编排。

## 版式重做：内容变平，材料只留给 chrome

参考 open-vetta 的页面：它的卡片是**实色面 + 0.5px 细线 + 圆角 12**，没有模糊也没有外投影。
我们之前把玻璃用在了所有东西上，页面读起来是"糊"而不是"通透"。

现在分层是明确的：**顶栏、输入条、弹层是玻璃**（它们真的浮在内容上），
**设置分组、列表、卡片是平的**（实色 + 细线）。

同时按它的排版收敛：
- 分组标题 13 / 600、字距 0.2；行标题 14 / 500；说明文字 11.5
- 行高 52 → 48（两行 64 → 58），分组间距 24 → 20，行间分隔 2 → 0.5
- 页面大标题 26 / 700、字距 −0.55，并用「前景色 → 72% 前景色」的对角渐变做文字填充

## 输入条上沿的「上下文潮线」

一条 2px 的线，显示上一次请求吃掉了多少上下文；点它看拆分（上次请求 / 其中缓存 / 上次输出 / 窗口）。
数字全部来自引擎回报的 `TokenUsage`——模型没声明窗口时**不画比例**，也不编分母。

## 长代码块可以收起

超过 48 行时，代码块标题条右边多一枚收起键：收起后留 12 行 + 底部渐隐 + 「展开全部 N 行」。
**不会自动截断**——自动截断最容易把正在读的位置弄丢。切换时如果这块的上沿已经滚出屏幕，
会补偿滚动位置，视线不动。

## 状态筛选收成一枚胶囊

原来那排「全部 / 运行中 / 待确认 / 未读」占一整行；现在收成一枚胶囊写当前条件与命中数
（`待确认 3`），点开是带计数和勾选的选项列表。省下的那一行还给了会话列表。

## 侧边栏变成翻页器

顶上一排页签（会话 / 文件），左右滑动即可翻页，点页签也能切。规格照 pi-web 的侧边栏实测值：
格间 1px 分隔、选中格顶部一条 2px 强调线、图标 13px、行高 44、切换 180ms（系统开了
"减少动态效果"就一步到位）。第 0 页继续向右拉，抽屉会跟手收回。

不想要？**设置 › 外观 › 侧边栏翻页器** 关掉就回到原来的一屏到底。横屏和矮窗自动用旧布局。

## 这一版的界面

全站换了一套**光感层**：玻璃的模糊与镜面强度不再是散落各处的魔法数字，而是几组
token，由「设置 › 外观」里的三档预设统一驱动。每一档你都能单独关掉某一项。

### 新增：外观 › 一键设置

| 档位 | 光感 | 玻璃 | 动画 | 刷新率 |
| --- | --- | --- | --- | --- |
| 完整光效 | 镜面 + 颗粒 + 棱镜边缘 | 开 | 灵动 | 跟满 |
| 专注（默认） | 镜面 + 光刃 | 开 | 只留必要反馈 | 自动 |
| 静默省电 | 不画光刃与辉光 | 关 | 关 | 交给系统 |

调过下面的细项后这里会显示「自定义」，不会假装你还在某一档。

### 新增：外观 › 表面配色

黑曜 / 暖炭两套中性底色，各含明暗两面（取自 obsidian-prism 的四段表面阶梯：
背景 → surface-1 → -2 → -3，每段只差 3–5%）。它和「深色模式」「强调色」三者正交。

强调色新增 **钴蓝** 与 **鸢尾**（同样由种子色推出整套角色色）。

### 新增：外观 › 光感与动效

- **光刃**：顶栏上沿的一道高光，只反映引擎真实状态（空闲 / 流式 / 跑工具 / 等你决定），
  空闲时是静止的，不跑动画；
- **边缘余晖**：等你决定、异常中止时，屏幕边缘一层极淡的光，不弹窗，4 秒后自己散；
- **预见性动画**：关掉后列表直接呈现，不做入场编排；
- **流光文字**：流式正文末尾像刚写上去的墨，由实到淡；生成结束立刻撤掉。
- **当前生效**：一行写出最终生效值——开关看着是开、实际被系统偏好压低时，这里能看见。

### 新增：性能 › 实测

最近 240 帧的平均 / 95 分位 / 最差 / 掉帧比例。打开这一页才开始采样，离开就停。
切到「静默省电」再回来，就能自己验证省电档是不是真的更省。

## 诚实的限制

- 光感的效果在真机上仍需按实际观感微调（镜面 0.095 在手机上可能偏暗）；
- 伙伴小屋的**舞台内部天空**仍是场景自己的配色，不跟随表面配色（页面边缘已跟随）；
- 这一版的改动由 CI 的 `flutter analyze` 把关，但**没有**在真机上做像素级验证；
  界面观感相关的调整欢迎带截图反馈。
