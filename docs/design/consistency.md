# 视觉一致性清单

这份文件回答一个问题：**"同一个东西，代码里有几种写法"**。
精致感来自克制的重复——用户说不出为什么，但会觉得"被认真做过"。
所以每加一个值，先在这里查有没有现成的。

## 圆角（只允许四档）

| 值 | 用在哪 |
|---|---|
| **8** | 控件：按钮、输入框、开关轨道、菜单项、分段高亮片 |
| **12** | 容器：分区卡、内容卡、图标砖外框、提示卡 |
| **16** | 浮层：对话框、popover、底部抽屉的上圆角 |
| **999** | 胶囊：`KitChip`、分段控件轨道、徽章 |

> 出现 10 / 18 / 20 / 22 / 28 一律并回上表最近一档。
> 例外：图片与头像用 `circle`。

## 间距（4 的倍数；三档递进）

| 值 | 用在哪 |
|---|---|
| **8** | 紧密相邻（图标与文字、同一行的两个键） |
| **12** | 卡内行间距、段落间距 |
| **16** | 卡内边距、左右页面留白（手机） |
| **24** | 分组之间、组标题与卡之间 |

> 6 / 10 / 14 / 18 / 20 只用于**光学补偿**（文字基线、图标视觉居中），
> 不用于结构性间距。

## 字号（正文区只有五档）

| 值 | 用在哪 |
|---|---|
| **14** | 正文、列表标题（中文取 13.5–14/500） |
| **12** | 说明、次级信息 |
| **11** | 元信息、时间、计数 |
| **15–16** | 分组标题、行内强调 |
| **24–26** | 页面大标题（仅一处渐变字：hero） |

行高：中文 ≥ **1.35**；正文 1.6。
字距：只有 ≥20px 的标题收 `-0.2 ~ -0.4`，正文不动。

## 透明度（只有五档，且都走 muted 阶梯）

| 档 | 用途 |
|---|---|
| **1.00** | 主文字 |
| **0.80** | 次级标题 |
| **0.70** | 说明文字 |
| **0.60** | 元信息 |
| **0.40** | 禁用、占位 |

底色/描边类透明度：**0.06（surface 填充）、0.075（前景填充）、0.12（选中填充）**。
> 0.05 / 0.07 / 0.08 这类相邻值肉眼不可分，一律并档。

## 动效时长（只有四档 + 光效例外）

| 值 | 用途 |
|---|---|
| **120ms** | 点亮、聚焦环、hover |
| **180ms** | 搬家（页签滑块、列表换页） |
| **240ms** | 标准过渡 |
| **320ms** | 提交类（保存、发送、落定） |

> 光效周期（1600 / 2400ms）不在此列，且**必须**在空闲时停帧。
> 所有时长必须经 `KitMotion.of(context)`，系统"移除动画"时归零。

## 检查方法

```bash
# 圆角 / 透明度 / 时长 的分布
python3 tool/design_audit.py
```

报告里任何一档出现超过 40 次、或出现表外值，就是还没收敛干净。
