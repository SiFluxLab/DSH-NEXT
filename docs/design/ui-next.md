# UI 升级：光感层与预见性动画

2026-11-21。这一份是本轮全站 UI 升级的总纲：方向、token、可选开关、性能预算，以及
分阶段落地的顺序。实现以 `app/lib/ui/theme/optics.dart` 为准；本文与源码冲突时以源码为准。

## 0. 一句话

**玻璃要有光学依据，动效要有信息量的理由。** 不做"到处发光"的玻璃拟态，也不做
"每个东西都在动"的演示稿：光只在有状态要表达的地方出现，动只在用户能从中读到
"从哪来、到哪去"的地方出现。

参考了三份实现，只取它们各自最强的一面：

| 来源 | 取什么 |
|---|---|
| [obsidian-prism](https://github.com/RMvdesi/obsidian-prism) | 光学 token 化（镜面 0.095 / 描边 0.115 / 模糊 20 / 颗粒 0.022）、四套配色、三档场景预设、**0fps 空闲语义**、三态边缘余晖、五级水墨淡入 |
| [open-vetta](https://github.com/openvetta/open-vetta) | 设计纪律：先定方向再写代码、留白与排版承担个性、**克制**（"出门前摘掉一件配饰"）、Reduce Motion 必须有降级 |
| [Aether](https://github.com/Zhou-Shilin/Aether) | 平台克制：能力没有证据就不启用、44pt 热区、空态与失败态要给方向、还原系统控件优先 |

## 1. 设计方向

产品是「口袋里的 Linux + 一个会干活的 Agent」。它自己的物质世界是：**水面、玻璃、光、
终端里的字符流**。所以视觉母题定为「静水上的光学玻璃」——玻璃是表面，光是状态，
水是背景的缓动。

- **颜色**：沿用现有 `DshPalette`（mist / night 两套表面）+ 6 套强调色，不新造配色。
  本轮不加主题，只把"光"的光谱固定下来：冷青 `#6EC8FF`、品红 `#FF9BD1`、暖金 `#FFE08A`，
  只出现在棱镜边缘，透明度 ≤0.10。
- **排版**：沿用现有 `typography.dart` 的字阶。光感层不引入新字号。
- **布局**：不改版面结构——这一轮改的是"表面怎么发光、动怎么发生"。
- **签名元素**：**光刃（Light Blade）**。玻璃表面上沿的一条极窄高光，只反映引擎真实状态：
  空闲呼吸 2.4s / 流式从左走到右 / 工具在跑中段来回 / 等你决定停在一半脉动。
  一个页面只有一条，不重复。

## 2. Token

`Optics`（ThemeExtension + `OpticsScope`）：

| token | 含义 | full | focus | silent |
|---|---|---:|---:|---:|
| `specular` | 玻璃上沿镜面高光 | 0.095 | 0.06 | 0 |
| `grain` | 纸纹颗粒 | 0.022 | 0 | 0 |
| `blade` | 光刃强度 | 1 | 0.6 | 0 |
| `prism` | 棱镜色散边缘 | 1 | 0.35 | 0 |
| `blurSigma` | 背景模糊 sigma | 20 | 12 | 0 |
| `anticipation` | 预见性动画 | on | on | off |
| `afterglow` | 三态边缘余晖 | on | on | off |
| `inkFade` | 流式文字五级淡入 | on | on | off |

**系统偏好永远赢**：`Optics.resolve` 在渲染时叠加三层信号——移除动画、关闭玻璃模糊、
省电模式——用户档位只是上限，不是命令。这样用户改回系统设置时我们不需要记"当初为什么关掉"。

## 3. 可选（设置里能关）

设置 › 外观 › 光感与动效，只有一个三选一 + 一条实时预览：

| 档位 | 给谁 | 效果 |
|---|---|---|
| 完整光感 | 想要最好看 | 玻璃、光刃、颗粒、棱镜全开 |
| 专注（默认） | 日常 | 玻璃与光刃保留，去颗粒，光刃只跟状态 |
| 静默省电 | 低端机 / 省电 | 不做模糊、不画光刃，只留描边与淡入 |

## 4. 预见性动画（anticipation）

"预见"的意思是：**在结果到达之前，先把结果的位置画出来**，让等待变成"东西正在到位"
而不是"空白正在等待"。三条落地规则：

1. **几何先到，内容后到**：页面/面板推入时立刻按目标几何绘制骨架与描边，数据到达后
   只替换内容，不改变布局——避免"先空后跳"。
2. **状态先于文案**：光刃、余晖、进度这类非文字信号先动，文字最后出现。用户先看到
   "有东西在发生"，再去读是什么。
3. **不做无信息的动**：没有状态变化的元素不加动画。列表进场只做一次（stagger ≤8 项），
   不在滚动中反复触发。

## 5. 性能预算

| 项 | 预算 |
|---|---|
| 常驻 `BackdropFilter` | 每屏 ≤ 3 处；silent 档为 0 |
| 光刃 | 1 个 CustomPainter / 屏，不新建图层，无 mask blur（prism 档一次小半径） |
| 空闲帧 | 无状态变化时全部停帧：光刃在 idle 态是静止的 35% 细线，不跑 ticker |
| 流式文字 | 只对新增片段做淡入，不包裹 DOM/Widget 节点 |
| 主题切换 | 一次全量 cross-fade（现有 `themeAnimationStyle`），不在切换中重排布局 |

## 7. 验收

- `flutter analyze` 与构建在 CI 通过；
- 三档预设切换后，**同一屏**能看出差别（预览条是硬要求）；
- 系统开"移除动画"后，光刃消失、转场变淡入，功能不受影响；
- 真机冷启动与对话流式期间的掉帧不劣于 1.0.x。
